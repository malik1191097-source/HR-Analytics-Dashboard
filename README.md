# HR Analytics Dashboard 📊

## 📌 Project Overview
The **HR Analytics Dashboard** is an Excel-based data analysis project designed to analyze employee information, workforce demographics, and employee attrition. It transforms raw HR data into meaningful insights through interactive visualizations, Pivot Tables, charts, and key performance indicators (KPIs).

The dashboard helps understand workforce trends and supports data-driven human resource decision-making.

## 🎯 Project Objectives
- Analyze employee data and workforce distribution.
- Calculate and understand employee attrition rates.
- Explore employee demographics and department-wise trends.
- Identify workforce patterns that may require further investigation.
- Present HR insights through a clear and informative dashboard.

## 📈 Key Performance Indicators (KPIs)
- Total Employees
- Attrition Count
- Active Employees
- Attrition Rate
- Average Employee Age

## 🔍 Key Analysis Areas
- Department-wise employee distribution
- Gender and age-group analysis
- Employee attrition analysis
- Education field analysis
- Job role and work experience analysis
- Years at the company and years in the current role
- Business travel and work-life balance

## 🛠️ Tools and Technologies
- **Microsoft Excel**
- Pivot Tables
- Charts and Data Visualization
- Data Analysis and KPI Reporting

## 💡 Key Insights
This project provides a structured view of workforce composition and employee attrition. It can help users explore patterns across departments, demographics, job roles, and employee experience.

The dashboard supports descriptive analysis; further investigation is needed before drawing conclusions about the causes of employee attrition.

- Understanding of HR metrics and employee attrition.
- Experience creating dashboards and KPI reports.
- Improved skills in data visualization and business reporting.
